# 0.12.6 — Integrazione con Mini B.I. e alert operativi

`OperationalReportsService.buildFromAlert()` consente di trasformare un alert B.I. in una segnalazione operativa precompilata.

Il flusso didattico consigliato è:

```text
KPI / alert B.I. → segnalazione operativa → referente → presa in carico → risoluzione
```
