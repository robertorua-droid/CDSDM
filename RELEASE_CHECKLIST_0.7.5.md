# 52. Pacchetto stabile per uso in classe 0.7.5

La versione **0.7.5** chiude il ramo 0.7.x come pacchetto stabile per uso didattico.

1. Verificare `firestore.rules`.
2. Creare Gruppo aziendale e inviti.

4. Eseguire backup prima dell’esercitazione.
5. Lanciare le suite in `tests/index.html`.
6. Usare il dataset demo solo su gruppi di prova.
7. Esportare backup e report QA finali.
